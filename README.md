# Aiden Quinn's EE Projects

A collection of electrical engineering projects completed during Aiden Quinn's degree. Each project lives in its own folder with source code and a project-specific README.

## Projects

### [Automatic Irrigation System](./automatic-irrigation-system)
A dual-Arduino irrigation controller. An Arduino Mega reads soil moisture sensors across 4 plots and drives solenoids/pumps, while a separate Arduino UNO handles a keypad + LCD user interface, communicating with the Mega over Serial.

### [Auto Card Dealer ("Electric Jacks")](./auto-card-dealer)
A joystick-controlled automatic card dealing machine. Uses a continuous-rotation servo to rotate a Lazy Susan to each seat, a micro servo to flick cards, and a stepper motor for seat indexing. Supports Blackjack, Poker, and Euchre for up to 4 players.
